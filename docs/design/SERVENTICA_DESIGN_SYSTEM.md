# SERVENTICA — Design System Architecture & Guidelines

## 1. Provisional Status & Visual Identity Principle
- **Light Theme Primary**: Designed with clean, high-contrast light surfaces (`#ffffff`, `#f8f9fa`) and rich warm accent accents.
- **Provisional Token Contract**: All visual sizes, radius scales, and card styles remain flexible to faithfully match the user's upcoming UI/UX design screenshots.

## 2. Component Hierarchy
- Atomic tokens (`colors`, `spacing`, `radii`, `typography`).
- Shared UI primitives (`Button`, `Card`, `Badge`, `Input`, `BottomSheet`, `StatusIndicator`).
